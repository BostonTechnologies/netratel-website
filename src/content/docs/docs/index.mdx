## Understand the pieces

**Web** is your operator interface. **API** handles authorization, durable state and the agent gateway. A native **Client** runs on each managed computer. CLI and MCP provide additional ways to use the platform; AI is optional.

[See the architecture](/docs/reference/architecture/) · [Choose a deployment](/docs/deployment/overview/) · [Understand the security model](/docs/reference/security/)

## Need a hand?

Start with [troubleshooting](/docs/guides/troubleshooting/). For a product issue, include your version, the affected feature and steps to reproduce it in a [GitHub issue](https://github.com/BostonTechnologies/netratel/issues). Every documentation page has an edit link for corrections.
